# PDFStripper Design Context

## Target Audience
- Privacy-conscious professionals handling sensitive documents (lawyers, accountants, doctors)
- Freelancers who need PDF tools but won't pay $13/mo for Adobe
- Students merging lecture notes, compressing submissions
- Small business owners handling invoices, contracts, proposals
- Ages 25-50, moderate tech comfort, care about privacy and speed

## Use Cases
- Merge multiple contract PDFs without uploading to a third-party server
- Compress large files for email attachment limits
- Split chapters out of large documents
- Add watermarks to draft deliverables
- Convert images to PDF for documentation
- Check PDF metadata and page counts

## Brand Personality / Tone
- **Trustworthy and private** — your files never leave the browser, and the design reinforces that
- **Fast and utilitarian** — a sharp tool, not a pretty face. Zero friction, zero waste.
- **Professional** — not playful, not corporate. Clean and competent.
- **Inspired by:** Vercel's density, Raycast's command palette, Figma's tool panels

## Visual Direction
- **Aesthetic:** Utilitarian toolbox — each tool is a focused workspace with clear input → action → output
- **Colors:** Deep black (#0a0a0b) base, teal-500 for primary actions, green for success, red for errors
- **Typography:** Space Grotesk for headings (geometric precision), DM Sans for body, JetBrains Mono for file sizes/metadata
- **Corners:** Small radius (rounded-lg max) — sharp and functional
- **Borders:** Crisp zinc-800, dashed for drop zones
- **Layout:** Narrow content width (800px max for tools), generous vertical spacing
- **Drop zones:** Prominent but not decorative — dashed border, subtle highlight on drag
- **File lists:** Dense, tabular — number, icon, name, size, actions
- **NEVER USE:** violet/purple/fuchsia, glassmorphism, gradient text, card-in-card, emoji icons, bounce animations

## Differentiator
Privacy-first messaging woven into the design. Every page subtly reminds users their files stay local. The shield icon and "100% client-side" badge in the footer aren't marketing — they're the product promise.

## Technical Stack
- Next.js 16 + TypeScript + Tailwind CSS
- Static export for GitHub Pages
- pdf-lib for manipulation, pdfjs-dist for rendering
- 100% client-side, zero backend
- Lucide React icons
- Mobile-first responsive
