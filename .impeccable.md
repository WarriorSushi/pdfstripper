# PDFStripper Design Context

## Target Audience
- Privacy-conscious professionals handling sensitive documents (lawyers, doctors, accountants)
- Freelancers needing PDF tools without paying $13/mo for Adobe
- Students merging lecture notes, compressing submissions
- Small businesses managing invoices and contracts

## Use Cases
- Merge multiple contract PDFs without uploading to third-party servers
- Compress large proposals to meet email size limits
- Split textbook chapters for focused study
- Add watermarks to draft deliverables
- Check PDF metadata and page info quickly

## Brand Personality / Tone
- **Trustworthy and private** — the #1 thing is "your files never leave your browser"
- **Utilitarian precision** — this is a workshop, not a showroom
- **Fast and direct** — drop file, get result, done
- **Technically honest** — explains what happens, doesn't hide behind marketing speak
- **Inspired by:** PDF24 (functionality), Linear (precision), terminal tools (directness)

## Visual Direction
- **Aesthetic:** Workshop/utility — clean surfaces, tool-like density, zero decoration
- **Colors:** Deep black (#0a0a0b) base, teal-500 for progress/success, red for destructive actions
- **Typography:** Space Grotesk for tool names and headings, DM Sans for descriptions, JetBrains Mono for file sizes/metadata
- **Corners:** Small radius (rounded-md to rounded-lg), precise edges
- **Borders:** Crisp zinc-800 lines, no blur, no glow, no glass
- **Effects:** None — let the functionality speak. Only animation is progress bars.
- **Layout:** Single-column focused tool pages, multi-column tool grid on homepage
- **NEVER USE:** gradient text, glassmorphism, bounce animations, emoji, decorative illustrations

## Differentiator
The privacy guarantee isn't marketing — it's architecture. Every tool processes in the browser using Web Workers. No file ever touches a server. Show the tech, not just claim it.

## Technical Stack
- Next.js 16 + TypeScript + Tailwind CSS
- pdf-lib for PDF manipulation (client-side)
- pdfjs-dist for rendering and text extraction
- Static export for GitHub Pages
- Lucide React icons
