# PDFStripper Design Context

## Target Audience
- Privacy-conscious professionals (lawyers, accountants, doctors) handling sensitive PDFs
- Freelancers and small businesses needing PDF tools without Adobe subscriptions
- Students merging lecture notes, compressing submissions
- Ages 22-50, value privacy and speed over feature bloat

## Use Cases
- Merge multiple contract PDFs without uploading to third-party servers
- Compress large files for email attachments
- Split specific pages from textbooks or reports
- Add watermarks to draft deliverables
- Check PDF metadata and extract embedded images

## Brand Personality / Tone
- **Trustworthy and private** — your files stay in your browser, period
- **Professional utility** — a sharp tool, not a colorful toy
- **Fast and no-nonsense** — drop, process, download, done
- **Inspired by:** Raycast's speed, Linear's density, Vercel's trust signals

## Visual Direction
- **Aesthetic:** Industrial file tool — clean grids, monospace values, precise spacing
- **Colors:** Deep black (#0a0a0b) base, teal-500 for actions, sky for links, green for success, amber for warnings
- **Typography:** Space Grotesk for headings, DM Sans for body, JetBrains Mono for file metadata
- **Corners:** Small radius (rounded-lg max), crisp edges
- **Borders:** Subtle zinc-800, no glass/blur effects
- **Upload zone:** Dashed border, clear drop target, obvious CTA
- **Motion:** Snappy 100-150ms, no bounce. Progress bars animate smoothly.
- **Layout:** Tool cards in tight grid, left-aligned descriptions, dense but breathable
- **NEVER USE:** violet, purple, fuchsia, gradient text, glassmorphism, emoji as icons, Inter font

## Differentiator
The trust signal: "Your files never leave your browser" prominently displayed. Every tool page shows a shield icon and privacy reminder. Processing happens via Web Workers — zero network requests.

## Technical Stack
- Next.js 16 + TypeScript + Tailwind CSS
- Static export for GitHub Pages
- pdf-lib for PDF manipulation, pdfjs-dist for rendering
- Web Workers for heavy processing
- Lucide React icons, DM Sans + Space Grotesk + JetBrains Mono
- Mobile-first responsive (px-4 sm:px-6 lg:px-8)
